# Echo Phrase

A linguist studies a long chant written as a string `s` of lowercase letters. A phrase
(a non-empty block of consecutive letters) is an echo if it appears in the chant at least
twice, at two different starting positions; the two appearances may overlap.

Print the length of the longest echo, or `0` if no phrase appears twice.

## Input
One line with the string `s` (1 <= |s| <= 100 000).

## Output
Print the length of the longest phrase that occurs at least twice.

## Example
Input:
```
banana
```
Output:
```
3
```
