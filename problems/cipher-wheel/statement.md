# Cipher Wheel

A spy's cipher wheel shifts every letter of a message along the alphabet by the same
amount `k`: with `k = 2`, `a` becomes `c` and `y` becomes `a` (the alphabet wraps around).
A negative `k` shifts backwards.

Given `k` and a message of lowercase letters, print the shifted message.

## Input
The first line contains `k` (-10^9 <= k <= 10^9).
The second line contains the message: 1 to 1 000 000 lowercase letters.

## Output
Print the shifted message.
