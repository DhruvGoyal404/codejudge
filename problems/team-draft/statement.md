# Team Draft

A relay race has `n` legs and the club has exactly `n` runners. Runner `i` would run leg
`j` in `t_ij` seconds. Every runner runs exactly one leg and every leg gets exactly one
runner.

Print the smallest possible total time of the team.

## Input
The first line contains `n` (1 <= n <= 16).
Each of the next `n` lines contains `n` integers: line `i` holds `t_i1 ... t_in`
(1 <= t_ij <= 10^6).

## Output
Print the minimum total time.
