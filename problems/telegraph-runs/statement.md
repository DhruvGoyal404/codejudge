# Telegraph Runs

An old telegraph office shortens long messages before sending them. Every maximal run of
equal consecutive letters is replaced by the letter followed by the length of the run, so
`aaabcc` is sent as `a3b1c2`.

Print the shortened form of a message.

## Input
One line with the message: 1 to 1 000 000 lowercase letters.

## Output
Print the shortened message.
