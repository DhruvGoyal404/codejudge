# Typo Distance

A spell checker measures how far a typed word is from a dictionary word. One edit inserts
a letter anywhere, deletes a letter, or replaces a letter with another.

Print the smallest number of edits that turn the first word into the second.

## Input
The first line contains the first word `s` (1 <= |s| <= 1000).
The second line contains the second word `t` (1 <= |t| <= 1000).
Both consist of lowercase letters.

## Output
Print the minimum number of edits.

## Example
Input:
```
kitten
sitting
```
Output:
```
3
```
