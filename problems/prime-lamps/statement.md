# Prime Lamps

A promenade has lamp posts numbered `1, 2, 3, ...`. For the festival, exactly the posts
whose number is prime get a coloured lamp (a prime is a number greater than `1` whose only
divisors are `1` and itself).

The organisers ask `q` questions: for a given `n`, how many coloured lamps are there on
posts `1..n`?

## Input
The first line contains `q` (1 <= q <= 100 000).
Each of the next `q` lines contains one integer `n` (1 <= n <= 10 000 000).

## Output
Print `q` lines: the number of primes not exceeding each `n`.
