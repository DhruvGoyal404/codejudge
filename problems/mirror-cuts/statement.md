# Mirror Cuts

A sign maker received a long banner text `s` of lowercase letters. The shop only prints
pieces that read the same forwards and backwards, so the banner must be cut into
consecutive pieces, each of them a palindrome (a single letter always is one).

Print the smallest number of cuts needed.

## Input
One line with `s` (1 <= |s| <= 2000).

## Output
Print the minimum number of cuts.
