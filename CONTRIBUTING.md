# Contributing

CodeJudge is a personal project and **does not accept contributions**: pull
requests will be closed without review. This keeps the code, the problem set
and the security model under one author's control.

You're welcome to:

- **report a bug** by opening an issue;
- **report a security problem privately**: see [SECURITY.md](SECURITY.md),
  never a public issue;
- **fork it**: the code is MIT-licensed ([LICENSE](LICENSE)). The problem
  statements and samples are not: they are all rights reserved.
